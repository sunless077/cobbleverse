Standard music for each stage. It plays during live auctions in that stage, unless a Pokémon has its own file in ../pokemon/.

Put the files in this folder and include the stage's word in the file name:
  Stage 1 (Legendary): file name contains "legendary"  (or stage1)
  Stage 2 (Mega):      file name contains "mega"       (or stage2)
  Stage 3 (Uber):      file name contains "uber"       (or stage3)

Examples:  mega-champion-diantha.mp3   legendary-battle.mp3   uber-final.mp3
If a stage has several files, one is picked at random each auction.
Order of preference during an auction: Pokémon file > stage file > general battle file > built-in chiptune.
Redeploy after adding files.
