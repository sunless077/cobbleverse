Standard music for each stage. Plays during live auctions in that stage.
Put the files in this folder and include the stage's word in the file name:
  Stage 1 (Legendary): "legendary"  (or stage1)   e.g. legendary-battle.mp3
  Stage 2 (Mega):      "mega"       (or stage2)   e.g. mega-champion-diantha.mp3
  Stage 3 (Uber):      "uber"       (or stage3)   e.g. uber-final.mp3
Several files for one stage = one is picked at random each auction.
