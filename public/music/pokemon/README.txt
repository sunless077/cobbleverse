Pokémon-specific music. Put a file here named after the Pokémon and it plays while that Pokémon is being auctioned.

  dialga.mp3            -> plays for Dialga
  mewtwo.mp3            -> plays for Mewtwo (and not for Mew)
  dialga+palkia.mp3     -> plays for either Dialga or Palkia (use + to share one file)
  mega-charizard-y.mp3  -> plays for Mega Charizard Y; charizard.mp3 would play for any Charizard form

Names are not case sensitive. Use .mp3 .ogg .wav or .m4a.
If no file matches, the normal battle music plays. Redeploy after adding files.
